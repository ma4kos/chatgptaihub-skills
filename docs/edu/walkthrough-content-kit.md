# Walkthrough — Content Creation Kit

**Pack id:** `content-creation-kit` (P1)  
**Audience:** Marketing/content owners at SMBs  
**Outcome:** Brief → editable draft; LinkedIn outline with hook/beats/CTA — **draft only**, no auto-publish / no auto-post.

## Skills in this pack

| Slug | Role | Catalog status |
|------|------|----------------|
| `content-brief-to-draft` | core | draft (P1) |
| `linkedin-post-outline` | addon | draft (strong P1 — promote after editorial) |

## Story (fictional) — ReminderFlow content lead

A two-person marketing function needs clinic-friendly posts without inventing SEO volumes or case-study percentages.

### Step A — Brief to draft (P1 draft)

1. Write a brief (audience, length, must-include, must-avoid).
2. Run [`content-brief-to-draft`](../../skills/content-brief-to-draft/SKILL.md) — [`examples/content-brief-to-draft.md`](./examples/content-brief-to-draft.md).
3. Human edits claim flags, inserts URL, publishes elsewhere.

**Quickstart blurb:** *Structured brief → draft with SEO notes and human-edit checklist.*

### Step B — LinkedIn outline (strong P1 draft)

1. Bullets / angle → [`linkedin-post-outline`](../../skills/linkedin-post-outline/SKILL.md).
2. Example: [`examples/linkedin-post-outline.md`](./examples/linkedin-post-outline.md).
3. Throttle Company Page posting — skill does not post.

**Quickstart blurb:** *Talking points → hooks, body beats, CTA, light hashtags — you paste into LinkedIn.*

## Success criteria

- [ ] Draft flags missing proof instead of inventing stats
- [ ] LinkedIn outline includes throttle / no-auto-post note
- [ ] Brand voice via placeholder name (`CONTENT_BRAND_VOICE`), not scraped persona packs
