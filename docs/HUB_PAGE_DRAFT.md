## What it is

ChatGPTAIHub’s **free skills marketplace** is a lean, editorial catalog of original skill files for everyday SMB work:

- Meeting notes → action owners and dates  
- Customer email triage and reply macros  
- Weekly ops briefs and sales pipeline rollups  
- Proposal outlines and content drafts  
- PR summaries and bug repro scripts for small product teams  

We optimize for **trust and determinism**, not skill count. Every listed pack must pass a public quality bar: original writing, secret-safe env placeholders, clear inputs/outputs, and SMB fit.

We are **not** a scraped mirror of other skill repos, **not** a place for private VPC connectors, and **not** Cap FIRE or unrelated personal-finance products.

## How to install (SMB short path)

1. Open Pages or GitHub and pick a skill under `skills/<slug>/`.  
2. Copy `SKILL.md` into your ChatGPT / Codex skills location (or paste into project instructions).  
3. Read **Secrets** — never paste API keys into the skill file; env **names** only.  
4. Dry-run on fictional data (your “Harbor Dental” or “Northwind Bakery” stand-in).  
5. Keep humans in the loop: you still send the email, publish the post, merge the PR.

Full guide: [INSTALL.md](https://ma4kos.github.io/chatgptaihub-skills/INSTALL.md) · Security expectations: [SECURITY.md](https://ma4kos.github.io/chatgptaihub-skills/SECURITY.md)
