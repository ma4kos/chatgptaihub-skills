# Getting started

1. Choose a published skill or content pack from `marketplace.json`.
2. Read its `SKILL.md`, especially Inputs, Secrets, and Out of scope.
3. Copy the skill into your host or paste its instructions into a project.
4. Run a dry pass with sanitized sample data.
5. Have a human review before any external action.

Start with `meeting-notes-to-actions`, `customer-email-triage`, or `outbound-email-draft`.
