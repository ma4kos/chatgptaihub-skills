# Install

Clone or download this repository, then copy a selected skill directory to your ChatGPT or Codex skills location. For example:

```bash
git clone https://github.com/ma4kos/chatgptaihub-skills.git
cp -R chatgptaihub-skills/skills/meeting-notes-to-actions ~/.codex/skills/
```

The path is host-specific. Validate the catalog locally with `python3 scripts/validate_catalog.py`. Never copy real secrets into a skill file.
