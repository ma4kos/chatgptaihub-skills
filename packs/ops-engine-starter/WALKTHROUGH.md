**Time:** ~30–45 minutes with fictional data first.

## Story (fictional) — Harbor Beans café group

Harbor Beans runs three cafés. Maya (GM) is tired of Discord huddles that produce no owners, and closing steps live only in her head.

### Step A — Meeting → actions

1. Install [`meeting-notes-to-actions`](../../skills/meeting-notes-to-actions/SKILL.md) via [`docs/INSTALL.md`](../../docs/INSTALL.md).
2. Paste the sample in [`docs/edu/examples/meeting-notes-to-actions.md`](../../docs/edu/examples/meeting-notes-to-actions.md).
3. Expect a decisions table, action rows with owners/`UNASSIGNED`, and open questions.

**Quickstart:** *Paste raw huddle notes; get owners, dues, and a follow-up checklist — no CRM required.*

### Step B — Weekly ops brief

1. At week’s end, collect wins / misses / risks / **stated** metrics only.
2. Run [`weekly-ops-brief`](../../skills/weekly-ops-brief/SKILL.md) with [`docs/edu/examples/weekly-ops-brief.md`](../../docs/edu/examples/weekly-ops-brief.md).
3. Cap “Next week” at five items; do not invent KPIs.

**Quickstart:** *Bullets in → one-page ops brief out for owners and shift leads.*

### Step C — Tribal knowledge → SOP

1. Ask Maya for closing bullets (no passwords/alarm codes in the paste).
2. Run [`sop-from-bullets`](../../skills/sop-from-bullets/SKILL.md) — see [`docs/edu/examples/sop-from-bullets.md`](../../docs/edu/examples/sop-from-bullets.md). Use Prompt B/C variants in the skill for café open or client kickoff.
3. Editor fills open gaps before training staff.

**Quickstart:** *Turn “how we actually close” bullets into a structured SOP draft.*

### Step D — SOP → checklist

1. Feed the reviewed SOP draft into [`checklist-from-sop`](../../skills/checklist-from-sop/SKILL.md).
2. Operators tick evidence fields on shift — see [`docs/edu/examples/checklist-from-sop.md`](../../docs/edu/examples/checklist-from-sop.md).

**Quickstart:** *Convert a runbook into a numbered day-of checklist with stop conditions.*

## Success criteria

- [ ] One meeting produced an action table with no guessed owners
- [ ] One weekly brief used only pasted metrics
- [ ] SOP + checklist loop completed on fictional Harbor Beans data
- [ ] No secrets pasted into skill files

## Safety

Never paste alarm codes, POS admin passwords, or live vault values. Refer to credential stores by **label only**.
