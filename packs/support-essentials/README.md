# Support Essentials

**Pack id:** `support-essentials` (P0 launch)  
**Audience:** Support leads / CX at SMBs  
**Catalog:** `marketplace.json` → `content_packs[]`

## Why this pack

Shared inboxes need triage buckets and reusable macros — without wiring a live helpdesk API into this free catalog. **No auto-send.**
